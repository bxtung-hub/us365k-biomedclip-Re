# Upload instructions

**GitHub account:** `bxtung-hub`  
Repository target: `https://github.com/bxtung-hub/us365k-biomedclip-reproducibility`

## Easiest web method

1. Download and extract the ZIP package prepared with this folder.
2. Open the repository on GitHub.
3. Choose **Add file -> Upload files**.
4. Upload the top-level files first: `README.md`, `CITATION.md`, and `UPLOAD_TO_GITHUB.md`.
5. Upload the folders in batches: `paper`, `code`, `results`, `reproducibility`, then `reviewer_evidence`.
6. Commit each batch to `main`.

All individual repository files were kept below the ordinary browser-upload size threshold used by GitHub at package-build time. The very large original checkpoint volumes are intentionally represented by cryptographic manifests rather than placed in normal Git history.
